# Sugar Crumb Bakery (Static HTML/CSS/JS)

This project is now a static site with:
- `index.html`
- `css/styles.css`
- `js/main.js`

## Run locally

1. Install dependencies:
`npm install`
2. Start local server:
`npm run dev`

## Build

`npm run build`

## GitHub Pages

This repo is configured for static deployment:
- `vite.config.js` uses `base: "./"` for project pages.
- Deploy command:
`npm run deploy`
